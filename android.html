Ladda ner Android-appen

Version 5.30 · 56 MB · Android 7.0 eller senare
APK för Android. Kan inte installeras på iPhone.

Så installerar du

  1. Öppna den här sidan på din Android-mobil och tryck på nedladdningsknappen.
  2. Öppna den hämtade filen Svensk-eHockey-5.30.apk.
  3. Om Android ber om det: öppna Inställningar och tillåt installation från webbläsaren du använder. Gå tillbaka och tryck på Installera.
  4. Öppna Svensk eHockey. Du kan stänga av installationstillåtelsen igen efteråt.

Uppdateringar

Nya APK-versioner delas här och på vår Discord. Installera uppdateringen ovanpå den befintliga appen.
